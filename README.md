# Course Recommendation System

## Project Overview
A smart course recommendation system that helps users find suitable online courses based on their interests, ratings, and preferences.

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Seaborn
- Matplotlib
- Scikit-learn

## Features
- Interactive dashboard
- Course recommendations
- Revenue and performance analysis
- Collaborative filtering
- User ratings
- Data visualization

## Project Structure
- app.py
- code.py
- courses.csv
- users.csv
- user_ratings.csv
- requirements.txt
- README.md

## Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
streamlit run app.py
```
